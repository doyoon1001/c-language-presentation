Code Review · 01

1부터 n까지의 합 코드 리뷰

문제 목표

사용자로부터 양의 정수 n을 입력받아 for 반복문으로 1부터 n까지의 모든 정수를 더하여 합계를 출력하는 프로그램을 작성한다.

변수 선언

int형 변수 n(입력값), i(반복 제어), sum = 0(누적합)을 선언합니다.

핵심 로직
  • for(i=1; i<=n; i++) 로 1~n 순회
  • sum += i 로 매 반복마다 누적
  • 초기값 sum = 0 설정 필수
사용 헤더
#include <stdio.h>
Execution Result · 01

1부터 n까지의 합 실행 결과

Terminal — 실행 결과
결과 분석

n을 입력하면 for 루프가 1부터 n까지 순회하며 sum에 누적합니다. n=10이면 55가 올바르게 출력됩니다.

핵심 포인트
  • sum = 0 초기화를 빠뜨리면 쓰레기값 누적
  • i <= n 조건으로 n 포함 보장
  • 가우스 공식 n(n+1)/2와 결과 일치
Code Review · 02

1부터 n까지의 홀수 합 코드 리뷰

문제 목표

사용자로부터 양의 정수 n을 입력받아 1부터 n까지의 정수 중 홀수만 골라 합산하여 출력하는 프로그램을 작성한다.

홀수 판별

나머지 연산자로 홀수 확인

if (i % 2 != 0) sum += i;
핵심 로직
  • for 루프로 1~n 전체 순회
  • % 2 != 0 조건으로 홀수 필터링
  • 조건이 참인 경우에만 sum 누적
사용 헤더
#include <stdio.h>
Execution Result · 02

1부터 n까지의 홀수 합 실행 결과

Terminal — 실행 결과
결과 분석

n을 입력하면 % 2 != 0 조건으로 홀수만 필터링해 합산합니다. n=10이면 1+3+5+7+9 = 25가 출력됩니다.

핵심 포인트
  • % 2 != 0이 홀수 판별의 핵심
  • 또는 i += 2로 홀수만 순회 가능
  • 짝수 합을 구하려면 조건을 == 0으로 변경
Code Review · 03

5개 값의 합계 코드 리뷰

문제 목표

5개의 정수를 차례로 입력받아 모두 더한 합계를 출력하는 프로그램을 작성한다. for 반복문 안에서 입력과 누적을 동시에 수행한다.

변수 선언

int형 변수 i(반복 제어), num(매 회 입력값), sum = 0(누적합)을 선언합니다.

핵심 로직
  • for(i=0; i<5; i++) 5회 반복
  • 루프 내부에서 scanf로 값 입력
  • sum += num 으로 누적합 계산
사용 헤더
#include <stdio.h>
Execution Result · 03

5개 값의 합계 실행 결과

Terminal — 실행 결과
결과 분석

5번에 걸쳐 정수를 입력하면 for 루프가 매 회 입력받아 sum에 누적합니다. 5개의 입력 후 최종 합계가 출력됩니다.

핵심 포인트
  • 루프 내 scanf로 반복 입력 처리
  • num 하나로 5개 값을 순서대로 처리
  • 개수를 바꾸려면 5만 수정하면 됨
Code Review · 04

유클리드 호제법 코드 리뷰

문제 목표

두 양의 정수 a, b를 입력받아 유클리드 호제법으로 최대공약수(GCD)를 계산하여 출력하는 프로그램을 작성한다.

유클리드 알고리즘

b가 0이 될 때까지 반복

r = a % b; a = b; b = r;

b = 0이 되면 a가 최대공약수

핵심 로직
  • while(b != 0) 조건으로 반복
  • % 나머지 연산으로 점진적 축소
  • 루프 종료 후 a가 GCD
Execution Result · 04

유클리드 호제법 실행 결과

Terminal — 실행 결과
결과 분석

두 수를 입력하면 while 루프가 나머지 연산을 반복합니다. 예: 48과 18 입력 시 최대공약수 6이 출력됩니다.

핵심 포인트
  • 나머지 연산(%)으로 두 수를 점진적으로 축소
  • b = 0이 될 때 a가 GCD
  • GCD로 두 수를 나누면 최소공배수 계산 가능
Code Review · 05

네모 그리기 코드 리뷰

문제 목표

가로 크기 w와 세로 크기 h를 입력받아 * 문자로 채워진 직사각형(네모)을 출력하는 프로그램을 작성한다.

이중 for 루프 구조

외부 루프 — 행(세로)

for(i=0; i<h; i++)

내부 루프 — 열(가로)

for(j=0; j<w; j++) printf("*");
핵심 로직
  • 외부 루프 1회 = 1행 출력
  • 내부 루프로 가로 w개의 * 출력
  • 행 끝에 printf("\n")으로 줄 바꿈
Execution Result · 05

네모 그리기 실행 결과

Terminal — 실행 결과
결과 분석

가로 w와 세로 h를 입력하면 이중 for 루프가 h×w 크기의 직사각형을 * 문자로 그려 출력합니다.

핵심 포인트
  • 외부 루프 = 행, 내부 루프 = 열
  • 내부 루프 후 \n으로 줄 바꿈
  • 이중 루프의 총 실행 횟수 = w × h
Code Review · 06

팩토리얼 구하기 코드 리뷰

문제 목표

양의 정수 n을 입력받아 n! (n 팩토리얼)을 계산하여 출력하는 프로그램을 작성한다. 1부터 n까지의 연속 곱셈이 핵심이다.

팩토리얼 정의

n! = 1 × 2 × 3 × … × n

0! = 1 (수학적 정의에 따라 특별 처리)

핵심 로직
  • 초기값 result = 1 설정 필수
  • for(i=1; i<=n; i++) 순회
  • result *= i 로 누적 곱셈
Execution Result · 06

팩토리얼 구하기 실행 결과

Terminal — 실행 결과
결과 분석

n을 입력하면 for 루프가 1부터 n까지 곱해 나갑니다. n=5이면 1×2×3×4×5 = 120이 출력됩니다.

핵심 포인트
  • 초기값 result = 1 (0으로 시작하면 항상 0)
  • n이 클수록 결과가 커져 오버플로우 주의
  • 큰 수는 long long형으로 선언 권장
Code Review · 07

별 삼각형 그리기 코드 리뷰

문제 목표

양의 정수 n을 입력받아 1행부터 n행까지 각 행 번호만큼 *을 출력하는 직각삼각형 패턴을 그리는 프로그램을 작성한다.

패턴 구조
*
* *
* * *
* * * *
핵심 로직
  • 외부 루프 i: 1 ~ n (행 번호)
  • 내부 루프 j: 1 ~ i (i개의 * 출력)
  • 외부 루프마다 \n으로 줄 바꿈
Execution Result · 07

별 삼각형 그리기 실행 결과

Terminal — 실행 결과
결과 분석

n을 입력하면 이중 for 루프가 각 행 i에 i개의 *를 출력합니다. n=4이면 1, 2, 3, 4개 순서로 직각삼각형이 그려집니다.

핵심 포인트
  • 내부 루프 상한이 고정값이 아닌 i
  • 역삼각형은 내부 루프를 n부터 감소
  • 총 출력 * 개수 = n(n+1)/2
