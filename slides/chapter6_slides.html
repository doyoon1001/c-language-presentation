Code Review · 01

성적계산기 코드 리뷰

문제 목표

사용자로부터 점수를 입력받아 if-else 조건문으로 학점(A~F)을 판별해 출력하는 프로그램을 작성한다.

변수 선언

int형 변수 score로 점수를 입력받고, char형 또는 문자열로 학점을 판별합니다.

핵심 로직
  • 90 이상 → A학점
  • 80 이상 → B학점
  • 70 이상 → C학점
  • 60 이상 → D학점
  • 60 미만 → F학점
사용 헤더
#include <stdio.h>
Execution Result · 01

성적계산기 실행 결과

Terminal — 실행 결과
결과 분석

점수를 입력하면 if-else if 분기를 통해 해당 학점이 출력됩니다. 점수 범위에 따라 A~F가 올바르게 판별됩니다.

핵심 포인트
  • else if로 조건을 순서대로 체크
  • 위에서 걸리면 아래 조건은 자동 생략
  • 마지막 else가 F학점 기본값
Code Review · 02

윤년 정의 코드 리뷰

문제 목표

사용자로부터 연도를 입력받아 윤년 여부를 판별해 출력하는 프로그램을 작성한다. 논리 연산자(&&, ||)를 활용한 조건 판별이 핵심이다.

윤년 조건

400의 배수

year % 400 == 0

4의 배수 AND 100의 배수 아님

year % 4 == 0 && year % 100 != 0
핵심 로직
  • % 나머지 연산자로 배수 판별
  • && AND 조건 / || OR 조건 결합
  • 조건이 참이면 "윤년", 거짓이면 "평년"
사용 헤더
#include <stdio.h>
Execution Result · 02

윤년 정의 실행 결과

Terminal — 실행 결과
결과 분석

연도를 입력하면 400 · 100 · 4의 배수 조건을 단계적으로 확인해 윤년/평년을 올바르게 판별해 출력합니다.

핵심 포인트
  • 400의 배수는 무조건 윤년
  • 100의 배수지만 400 아니면 평년
  • 4의 배수면 윤년, 나머지는 평년
Code Review · 03

근의공식 코드 리뷰

문제 목표

계수 a, b, c를 입력받아 이차방정식 ax² + bx + c = 0의 근을 근의공식으로 계산하여 출력하는 프로그램을 작성한다.

근의공식

x = (-b ± sqrt(b²-4ac)) / 2a

판별식 D = b² - 4ac 먼저 계산

D ≥ 0 이면 실근, D < 0 이면 허근

핵심 로직
  • math.h의 sqrt()로 제곱근 계산
  • double형으로 정밀한 실수 계산
  • 컴파일 시 -lm 옵션 필요
Execution Result · 03

근의공식 실행 결과

Terminal — 실행 결과
결과 분석

a, b, c를 입력하면 판별식 D = b²-4ac를 계산한 뒤 실근 또는 허근 여부를 판별해 두 근을 출력합니다.

핵심 포인트
  • sqrt()는 math.h 포함 필요
  • 판별식 D < 0이면 허근 처리
  • double형으로 소수점 정밀도 확보
