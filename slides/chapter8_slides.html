Code Review · 01

팩토리얼 계산 함수 코드 리뷰

문제 목표

양의 정수 n을 입력받아 별도의 함수로 n! (n 팩토리얼)을 계산하고 결과를 main에서 출력하는 프로그램을 작성한다.

함수 구조

팩토리얼 함수 선언

int factorial(int n)
핵심 로직
  • 함수 내부에서 for 또는 재귀로 n! 계산
  • 초기값 result = 1 설정 필수
  • main에서 함수 호출 후 결과 출력
사용 헤더
#include <stdio.h>
Execution Result · 01

팩토리얼 계산 함수 실행 결과

Terminal — 실행 결과
결과 분석

n을 입력하면 factorial 함수가 호출되어 n!을 계산합니다. n=5이면 1×2×3×4×5 = 120이 출력됩니다.

핵심 포인트
  • 함수로 분리하면 재사용성이 높아짐
  • 초기값 result = 1 (0이면 항상 0)
  • 큰 수는 long long형 선언 권장
Code Review · 02

온도 변환기 코드 리뷰

문제 목표

섭씨(℃) 온도를 입력받아 변환 함수를 통해 화씨(℉)와 켈빈(K)으로 변환하여 출력하는 프로그램을 작성한다.

변환 공식

섭씨 → 화씨

F = C × 9/5 + 32

섭씨 → 켈빈

K = C + 273.15
핵심 로직
  • double형으로 실수 계산 처리
  • 변환 함수에 섭씨값을 인자로 전달
  • 함수가 변환 결과를 return으로 반환
Execution Result · 02

온도 변환기 실행 결과

Terminal — 실행 결과
결과 분석

섭씨 온도를 입력하면 변환 함수가 화씨와 켈빈 값을 각각 계산하여 반환합니다. 입력한 값에 따라 소수점 두 자리로 출력됩니다.

핵심 포인트
  • 9.0/5.0으로 실수 나눗셈 처리 (정수 나눗셈 주의)
  • 함수의 반환값을 변수에 저장 후 출력
  • double형으로 정밀도 확보
Code Review · 03

소수 찾기 코드 리뷰

문제 목표

양의 정수 n을 입력받아 2부터 n까지의 정수 중 소수(Prime Number)를 모두 찾아 출력하는 프로그램을 작성한다.

소수 판별 원리

2부터 √n까지 나눠 봄

for(j=2; j<i; j++) if(i%j==0) break;
핵심 로직
  • 외부 루프로 2~n 각 수를 순회
  • 내부 루프에서 약수 존재 여부 확인
  • 약수가 없으면 소수로 출력
사용 헤더
#include <stdio.h>
Execution Result · 03

소수 찾기 실행 결과

Terminal — 실행 결과
결과 분석

n을 입력하면 이중 루프가 각 수의 약수를 확인하여 소수만 출력합니다. n=20이면 2, 3, 5, 7, 11, 13, 17, 19가 출력됩니다.

핵심 포인트
  • 약수가 하나도 없으면 소수
  • 내부 루프 상한을 √n으로 줄이면 효율 향상
  • break로 불필요한 반복 즉시 종료
